Share the exact email or cell in one click

Workspace Link Copier adds a Share button to Gmail™ and Google Sheets™. One click copies a link to exactly what you're looking at, and the link works for your colleagues too.

Download (.zip) How to install
  • Free and open source
  • No permissions
  • Nothing leaves your browser

Why

Linking to one thing shouldn't take six steps

The address bar link to an email only works for you, and getting a link to a single cell is buried in a menu.

Link to an email 6 steps → 1

  1. Open ⋮ → Show original
  2. Find and copy the Message-ID
  3. URL-encode it
  4. Add the search prefix
  5. Build the full URL
  6. Paste it
Click Share. Done.

Link to a cell 4 clicks → 1

  1. Right-click the cell
  2. View more cell actions
  3. Get link to this cell
  4. Copy
Click Share. Done.

Features

A button that should've already been there

It sits among Google's own header icons, matches their colour in light, dark and picture themes, and confirms each copy with a short message at the bottom of the screen. Try the demos below.

Gmail: link to the email

Open a conversation and click Share, just left of the ? icon. You get a link that finds the conversation in anyone's mailbox if they received it.

  • Uses the first email in the thread, so everyone on the thread can open it.
  • Leaves out /u/0/, so it opens in the recipient's default account.
  • Gets the link ready as soon as you open the thread, so the copy is instant.

Sheets: link to the cell or range

Select a cell or range and click Share, just left of the version-history icon. The link opens the right file and tab with your selection highlighted.

  • Works for single cells (D31), ranges (C30:G30), whole columns and whole rows.
  • Keeps the same link format as Sheets' own "Get link to this cell".
  • For a named range, it copies a link to the tab and tells you why.

Install

Up and running in a minute

Works in Chrome 111 or newer.

  1. Download

    Download the .zip and unzip it to a folder you'll keep. Chrome loads the extension from that folder.

  2. Open extensions

    Go to chrome://extensions and turn on Developer mode (top right).

  3. Load unpacked

    Click Load unpacked and choose the unzipped folder (the one containing manifest.json).

  4. Reload your tabs

    Reload any open Gmail or Sheets tabs. The Share button appears in the top-right header.

Updates don't install automatically yet. To update, download the new .zip, replace the folder, and click reload on the extension in chrome://extensions. You can also use the button with the keyboard: Tab to it and press Enter.

Privacy

Everything stays in your browser

The extension has no servers, no analytics, and asks Chrome for no permissions.

No permissions

It only runs on mail.google.com and Google Sheets, to add its button. No OAuth, no Google APIs, no sharing changes.

No data collection

No tracking, no cookies, no accounts. Links live in the open tab's memory and disappear when you close it.

One local request

In Gmail it reads the email's "Show original" page from Gmail, using your own session, to find the Message-ID.

Good to know

Limitations

  • Gmail links work for people who received the email. The link searches for the first message of the thread, so it only finds the conversation in mailboxes that contain that message.
  • Named ranges in Sheets aren't supported. You get a link to the tab instead, and a message saying so.
  • Google updates its UI from time to time. If the button can't find its usual spot, it shows up in the top-right corner instead, and an update will put it back in place.
